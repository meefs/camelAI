# shadcn Components

Quick reference of available components. Use MCP tools for details and examples.

## Form & Input
- **Form** - React Hook Form + Zod validation
- **Field** - Input with label and error messages
- **Button** / **Button Group** - Multiple variants
- **Input** / **Input Group** - Text input with prefix/suffix
- **Input OTP** - One-time password input
- **Textarea** - Multi-line text
- **Checkbox** / **Radio Group** - Selection inputs
- **Select** - Dropdown
- **Switch** - Toggle
- **Slider** - Range input
- **Calendar** / **Date Picker** - Date selection
- **Combobox** - Searchable autocomplete
- **Label** - Form labels

## Layout & Navigation
- **Sidebar** - Collapsible app sidebar
- **Tabs** - Tabbed interface
- **Accordion** - Collapsible sections
- **Breadcrumb** - Navigation breadcrumbs
- **Navigation Menu** - Accessible nav with dropdowns
- **Separator** - Visual divider
- **Scroll Area** - Custom scrollbars
- **Resizable** - Resizable panels

## Overlays & Dialogs
- **Dialog** - Modal
- **Alert Dialog** - Confirmation prompts
- **Sheet** - Slide-out panel
- **Drawer** - Mobile-friendly drawer (Vaul)
- **Popover** - Floating content
- **Tooltip** - Hover context
- **Hover Card** - Card on hover
- **Context Menu** - Right-click menu
- **Dropdown Menu** - Dropdown actions
- **Menubar** - Horizontal menu
- **Command** - Command palette (cmdk)

## Feedback & Status
- **Alert** - Messages/notifications
- **Toast** - Toast notifications (Sonner)
- **Progress** - Progress bar
- **Spinner** - Loading spinner
- **Skeleton** - Loading placeholder
- **Badge** - Labels/status indicators
- **Empty** - Empty state

## Display & Media
- **Card** - Container component
- **Avatar** - User profiles
- **Table** / **Data Table** - Data display with sorting/filtering
- **Chart** - Charts (Recharts)
- **Carousel** - Image carousel (Embla)
- **Aspect Ratio** - Maintain aspect ratio
- **Typography** - Text styles
- **Kbd** - Keyboard shortcuts

## Utility
- **Collapsible** - Collapsible container
- **Toggle** / **Toggle Group** - Toggle buttons
- **Pagination** - List/table pagination

---

**Install:** `npx shadcn@latest add <component>`

**Search blocks:** `mcp__shadcn__search_items_in_registries(registries: ["@shadcn"], query: "sidebar")`
